# 05 — Phone check

What can only be checked on a real phone. Do it once on an iPhone and once on an Android.

Open **https://mr-flowjangles.github.io/cubeSolver/** in Safari (iPhone) or Chrome (Android).

## Install and offline

- [ ] Add to Home Screen (iPhone: Share → Add to Home Screen; Android: menu → Install app).
- [ ] Open it from the home screen icon. It opens full screen, no browser bar.
- [ ] Turn on airplane mode, close and reopen it. It still works.

## Cube and levels

- [ ] Drag the cube to spin it. Tap move buttons; turns animate smoothly.
- [ ] Pass Learn the controls. XP and a badge appear.
- [ ] Close the app and reopen. Progress is still there.
- [ ] Turn on ADA support. Shapes appear on stickers.

## Camera scan (needs a real cube)

- [ ] Solve my cube → Scan with camera. The camera asks for permission, then shows the guide.
- [ ] Scan all 6 faces in normal room light.
- [ ] Count wrong stickers on the check screen: ____ (expect 0–2).
- [ ] Fix any, tap Check & solve, follow the guide to a solved cube.

## Timer

- [ ] Time one real solve. Best and average show.

Report anything that fails; it becomes a fix before v1.0.0.
